# UI 进阶能力阶段复盘

本阶段对应课程第 28-41 节，重点是在掌握常用 UGUI 控件后，继续理解事件、坐标、裁剪、渲染和布局能力。

## 已学习内容

- 使用 Sprite Atlas 整理 UI 图片资源。
- 通过 UI 事件监听接口和 EventTrigger 处理按下、抬起、拖拽等交互。
- 使用 `RectTransformUtility.ScreenPointToLocalPointInRectangle` 将屏幕坐标转换为 UI 局部坐标。
- 使用 Mask 的透明区域裁剪子级 UI，并完成圆形头像练习。
- 使用独立 UI 摄像机与 `Screen Space - Camera` Canvas 分离场景和 UI 渲染。
- 了解通过图片透明度阈值限制异形按钮的有效点击区域。
- 了解 Layout Group、Content Size Fitter 和 Layout Element 的职责。
- 使用 CanvasGroup 统一控制 UI 透明度、交互和射线阻挡。

## 完成的主要练习

- 长按按钮 0.2 秒后开始蓄能，蓄能完成后恢复 HP。
- 使用 EventTrigger 制作可拖拽摇杆，限制拖动范围，并控制角色移动与转向。
- 将摇杆拖拽位置由屏幕坐标转换到父级 UI 的局部坐标。
- 使用圆形 Mask 将方形头像裁剪为圆形。

## 调试与实践收获

- UI 事件应在初始化阶段注册一次，不能放入 `Update` 重复注册。
- EventTrigger 的拖拽回调触发次数由指针事件决定，不需要额外乘以 `Time.deltaTime`；持续移动逻辑仍应按帧率无关方式处理。
- 操作 RectTransform 时，应分清屏幕坐标、世界坐标、局部坐标和 `anchoredPosition`。
- `Screen Space - Overlay` 更简单；需要模型、粒子或独立渲染控制时，可以使用 UI 摄像机和 `Screen Space - Camera`。
- 四元数旋转目前以理解用途和跟随练习为主，后续学习 Unity 相关内容时再深入。
