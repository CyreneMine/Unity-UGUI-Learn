## 提示面板

- `TipPanel` 通过 `UIManager` 动态创建。
- 支持动态修改提示文本。
- 确认按钮关闭提示面板。
- 调试时发现：UI 最终显示位置不等于射线检测范围，文本对象的 RectTransform 如果覆盖按钮，仍会挡住按钮点击。

## 登录面板

- 已制作 `Resources/UI/LoginPanel` Prefab。
- 面板包含账号输入、密码输入、记住密码、自动登录、登录按钮和注册按钮。
- 已绑定 `LoginPanel` 脚本引用。
- 当前逻辑已读取 `LoginData`，并根据记住密码和自动登录状态恢复输入框与 Toggle。

## 收尾检查

- 自动登录失败时保留登录面板，并通过提示面板告知账号或密码错误。
- 选服面板中“上次登录服务器”显示使用 `choiceServerId - 1` 访问服务器列表，避免服务器 id 与 List 下标错位。
- `GameScene` 已加入 Build Settings，服务器面板开始游戏按钮可以加载游戏场景。

## 注册面板

- 已制作 `Resources/UI/RegisterPanel` Prefab。
- 面板包含账号输入、密码输入、确认按钮和取消按钮。
- 注册成功后写入 `RegisterData`，回到登录面板并回填账号与密码。
- 注册取消时返回登录面板。

## 服务器面板

- 已制作 `Resources/UI/ServerPanel` Prefab。
- 当前完成重点是面板 UI 拼接，属于第 52 节内容。
- 已新增 `ServerPanel` 脚本，处理开始游戏、返回登录和切换服务器按钮。
- 开始游戏按钮会隐藏服务器面板并加载 `GameScene`。
- 返回按钮会隐藏服务器面板并重新显示登录面板。
- 切换服务器按钮会隐藏服务器面板并显示选服面板。
- 登录成功后会保存登录数据；如果已有服务器选择，则显示服务器面板。
- `LoginData` 中新增 `choiceServerId` 用于记录当前选择的服务器。
## 选服面板

- 已制作 `Resources/UI/ChooseServerPanel` Prefab。
- 已制作 `ServerLeftItem` 与 `ServerRightItem` Prefab，用于动态创建服务器区间按钮和服务器按钮。
- 已新增 `ServerInfo` 数据结构，并通过 `StreamingAssets/ServerInfo.json` 提供服务器列表数据。
- 左侧按钮按 5 个服务器为一组切换右侧列表。
- 右侧按钮显示服务器编号、名称、新服标记和服务器状态图标。
- 选择服务器后记录 `choiceServerId`，关闭选服面板并进入服务器确认面板。
- 选服面板顶部会显示上次登录服务器；没有选择服务器时显示“无选区”。
