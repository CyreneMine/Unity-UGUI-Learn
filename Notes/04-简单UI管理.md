# 简单 UI 管理阶段复盘

本阶段对应课程第 42-45 节，并开始进入综合 UI 案例。

## 项目准备

- 在 `Assets/UGUI_Demo/` 中独立管理综合案例的美术、场景、脚本和 Resources。
- 将默认 JSON 数据目录放在标准的 `Assets/StreamingAssets/` 路径。
- 导入并复用 JSON 学习项目中的 `JsonMgr` 与 LitJson。
- 使用主摄像机和 UI 摄像机分别渲染场景与 UI。

## 面板基类

- 使用 `CanvasGroup` 实现面板淡入与淡出。
- 通过抽象 `Init()` 让不同面板实现自己的初始化逻辑。
- 隐藏动画完成后，通过回调通知 UIManager 销毁面板。

## UIManager

- 使用面板类型名称作为 Resources 路径与字典键。
- 动态创建面板后，将其放到 Canvas 下并保存引用。
- 支持淡出隐藏和立即隐藏，两种方式都会销毁整个面板 GameObject 并移除字典记录。
- 当前项目约定由制作流程保证 Prefab 路径和面板组件正确，因此没有额外添加资源与组件缺失检查。

## 提示面板与调试记录

- 已制作 `Resources/UI/TipPanel` Prefab，并接入动态提示文字和确认按钮关闭逻辑。
- 曾出现画面中文字位置正常，但确认按钮无法点击的问题。
- 原因是只调整了文字显示效果，没有同步调整文本对象的 RectTransform，文本框实际范围覆盖了按钮并拦截射线。
- 排查 UI 点击问题时，应观察对象真实的 RectTransform 范围，而不能只看文字或图片最终显示的位置。
