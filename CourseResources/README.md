## 使用原则

- 课程视频按编号顺序学习。
- 练习题优先独立完成，再对照参考代码。
- 参考代码只用于定位问题和复盘，不直接覆盖自己的练习。
- 完整 Demo 用于课程后期理解整体结构，不在基础阶段提前照搬。
- 教程资源保留在原本地目录，不复制进 Unity 项目，避免仓库体积过大。
